# Codex App Plugin

The plugin connects Codex to a local Canvas Agent, allowing Codex to open Infinite Canvas, read and create nodes, connect nodes, and start generation workflows. Its source is in `plugins/infinite-canvas/`.

## Ask Codex to install it

Send this request to Codex:

```text
Install the project-owned Infinite Canvas Codex plugin from https://github.com/sucheng1101/infinity-canvas.git.
Run `codex plugin marketplace add https://github.com/sucheng1101/infinity-canvas.git`,
then install `infinity-canvas@infinity-canvas`. Validate the installation and tell me whether a new
conversation is required to load the Skill and MCP tools.
```

## Manual installation

```bash
codex plugin marketplace add https://github.com/sucheng1101/infinity-canvas.git
codex plugin add infinity-canvas@infinity-canvas
```

Start a new Codex conversation after installation so the Skill and MCP tools load completely.

For development from this repository:

```bash
cd /path/to/infinity-canvas
codex plugin marketplace add "$(pwd)"
codex plugin add infinity-canvas@infinity-canvas
```

## Usage

In a new Codex conversation, ask it to open Infinite Canvas, create a canvas, and connect Codex. The plugin starts `@sucheng1101/canvas-agent`, reads its `Canvas URL`, opens the project-owned site at `https://sucheng1101.github.io/infinity-canvas/`, and creates and connects a canvas. It starts a local frontend only when explicitly requested.

You can then ask Codex to summarize the current canvas, create prompts from selected nodes, or organize nodes into a generation workflow.

Reinstall or refresh the plugin after changing its manifest, MCP configuration, Skills, exposed MCP tools, app, or entry scripts. The agent's default MCP command is:

```bash
npx -y @sucheng1101/canvas-agent@latest mcp
```
