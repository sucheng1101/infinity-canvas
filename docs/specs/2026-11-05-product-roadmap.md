# 产品路线：从生图到视频到短剧

> 说明：本文的「现状盘点」依据仓库代码核实；「竞品借鉴」为产品经验判断，本轮未能联网核实（本机搜索凭据缺失），落地前建议各自打开一次真实产品复核。

## 1. 现状盘点（已核实）

**已有创作入口**

| 页面 | 路由 | 能力 |
| --- | --- | --- |
| 工作台 | `/workbench?mode=image\|video` | 单张/批量生图、文生视频、图生视频、历史记录 |
| 无限画布 | `/canvas`、`/canvas/:id` | 节点编排、图片/文本/视频/音频/配置/组节点、参考连线、撤销重做 |
| 电商画布 | `/projects`、`/projects/:id` | 对话式生成方案 → 模板化画布 → 三图一键生成 → QA 检查 |
| 提示词库 | `/prompts` | 多远程来源聚合、分类/标签、缓存到 IndexedDB |
| 模型广场 | `/model-plaza` | 统一售价、订阅权益、质量档位、性能概览 |
| 我的资产 | `/assets` | 资产列表、数据看板、使用日志、积分与充值、渠道 |

**已有平台能力**：账户/会话、积分与订阅、模型渠道与路由、Relay 托管生成、用量与财务、管理后台。

**关键结构性事实**

- 「对话生成结构化方案 → 落到画布模板 → 批量生成 → 质量检查」这套模式已经在电商场景跑通，**它是一个可复用的工作流模板引擎**，而不只是一个电商功能。
- 提示词库是「文本条目 + 分类 + 标签」，没有与模型参数、质量档位、镜头语言绑定。
- 资产库只有 `text / image / video` 三种，没有音频、字体、图标、品牌物料，也没有标签检索与授权信息。
- 画布是唯一的「工作流容器」，但缺少「可保存/可分享的工作流模板」概念（目前项目=画布实例，不是模板）。

## 2. 用户旅程：三阶段养成

| 阶段 | 用户目标 | 我们需要提供 | 现状差距 |
| --- | --- | --- | --- |
| L1 生图 | 出一张能用的图 | 模板化提示词、参考图、批量出图、简单修图（裁剪/放大/局部改） | 基本具备，缺「风格模板」与「词库结构化」 |
| L2 视频 | 让图动起来、做短视频 | 首帧/尾帧、运镜预设、时长/比例、批量、图生视频一致性 | 有基础生成，缺运镜模板、缺视频素材库、缺分镜意识 |
| L3 短剧 | 多镜头成片 | 剧本→分镜→角色卡（一致性）→逐镜生成→配音/字幕→合成导出 | 基本为零，只有画布可作骨架 |

**结论**：不要为三个阶段做三套产品。应该做**一套「对话 + 分镜画布」**，用模板区分阶段——这正是电商套图已经验证过的形态。短剧不是新应用，是「分镜模板 + 角色一致性 + 合成导出」三块能力的叠加。

## 3. 竞品借鉴：取其精华

> 以下为经验判断，未联网核实。

| 类型 | 代表形态 | 精华（值得抄） | 糟粕（不要抄） |
| --- | --- | --- | --- |
| 灵感社区型 | LiblibAI / Civitai / OpenArt | 作品页直接给出「复现参数」；模型与工作流可被收藏复用；榜单驱动供给 | 参数噪音大、内容审核成本高、新手看不懂 |
| 一站式创作台 | 即梦 / 可灵 / 海螺 | 模板一键出片；运镜与镜头预设做成可点选；首尾帧交互直接 | 黑盒、参数不可控、无法拼装长流程 |
| 专业工作流 | ComfyUI / Krea / Freepik AI | 节点化、可保存工作流、批量队列、成本可见 | 门槛高、界面劝退普通用户 |
| 短剧管线 | 白日梦 / 讯飞绘镜 / SkyReels 类 | 剧本→分镜→角色→配音→合成的完整链路；角色一致性靠「角色卡 + 参考图」 | 全流程黑盒、单点失败就整条重跑、贵 |
| 素材/模板市场 | Freepik / Canva / 稿定 | 结构化标签检索、授权清晰、模板可二次编辑 | 与创作工具割裂，导不进自己的编辑器 |
| 提示词库 | PromptHero / OpenArt | 按主体/风格/镜头/光线分面；一键套用 | 只有文本堆砌，不绑定参数与模型 |

**我们该抄的三件事**

1. **分面化词库**（PromptHero 精华）——但绑定我们自己的质量档位与模型。
2. **工作流模板**（ComfyUI 精华 + 电商套图已有形态）——模板即画布，一键实例化。
3. **角色卡一致性**（短剧管线精华）——一张角色卡 = 参考图 + 固定描述 + 固定种子/风格，跨镜头复用。

**我们不该抄的三件事**

1. 不做一个「大而全的模型广场」去拼价格——我们已经有统一路由与订阅，重点应是「选对模型」而不是「展示所有模型」。
2. 不做黑盒一键成片——用户最终要能改每一个镜头，否则专业用户流失。
3. 不做纯文本词库——没有参数绑定和画布落地，词库就是死文档。

## 4. 导航栏：从「工具集合」改为「创作路径」

现状是 6 个平级入口（画布/工作台/项目/提示词/模型广场/资产），用户看不出「我该从哪开始」。

### 建议的一级导航（5 项）

| 一级 | 含义 | 承载路由 | 说明 |
| --- | --- | --- | --- |
| **创作** | 从零开始做一条内容 | `/workbench`（图/视频两个 tab） | 保留现有工作台，作为「快速出片」入口 |
| **画布** | 我的项目与工作流 | `/canvas`、`/projects` | 合并两个项目列表：普通画布 + 电商画布 + 未来的分镜画布 |
| **素材** | 材料库（图/视频/音频/字体） | `/assets` | 从「个人资产」升级为「材料库」，见第 6 节 |
| **灵感** | 词库 + 案例 + 模板 | `/prompts`（升级为灵感中心） | 词库、优秀案例、工作流模板三合一 |
| **我的** | 账户、额度、渠道、用量 | `/assets/wallet`、`/channels`、`/assets/usage` | 现在散落在两处，应收进一个下拉 |

**模型广场**建议从一级导航降级：并入「创作」页的模型选择器 + 「我的」里的订阅入口。原因：普通用户不需要「逛模型」，需要「选到对的模型」；模型广场的浏览价值由「灵感」承担。

### 二级结构（创作页内）

```
创作
├─ 图片  ├─ 文生图
│        ├─ 图生图 / 参考图
│        └─ 精修（裁剪/放大/局部改）
└─ 视频  ├─ 文生视频
         ├─ 图生视频（首帧/尾帧）
         └─ 分镜成片（未来）
```

### 新手引导（关键）

首屏不要直接甩空画布。建议 `/app` 首页做成「三张卡片」：

1. **做一张商品图**（进入电商模板，填商品名即可）
2. **做一条短视频**（进入视频工作台，选模板）
3. **从空白画布开始**（给老用户）

这样三个阶段的新用户都能在 30 秒内看到第一张成品，而不是先学画布。

### 迁移成本

- 现有路由全部保留，只改顶部导航分组与首页，不动页面实现 → 半天到 1 天。
- `navigation-tools.ts` 需要从「slug 列表」改成「分组 + 子项」结构，`app-top-nav.tsx` 跟着改。

## 5. 词库：从「提示词列表」升级为「结构化创作词典」

### 5.1 数据模型（建议）

```ts
type PromptFacet = {
  id: string;
  category: "subject" | "style" | "lighting" | "camera" | "composition" | "color" | "material" | "mood" | "negative";
  zh: string;          // 中文名
  en: string;          // 模型实际吃的英文词
  aliases: string[];   // 别名词，便于搜索
  modelHints?: string[];   // 适用模型能力，如 ["image", "video"]
  params?: Record<string, unknown>; // 绑定参数：如运镜=push-in、质量档位
  examples?: string[]; // 示例图 URL
};
```

结构化词条的价值：**点一下就能插入到当前节点提示词的正确位置**，而不是让用户自己去拼英文。

### 5.2 分层供给

| 层 | 内容 | 来源 | 维护 |
| --- | --- | --- | --- |
| 官方精选 | 风格 30 个、镜头 20 个、光线 15 个、构图 12 个（起步量） | 运营 + 设计 | 我们维护 |
| 行业模板 | 电商（已有 12 场景）、短剧（校园/古风/都市）、人像、产品 | 我们 + 客户共创 | 按行业迭代 |
| 社区投稿 | 用户保存的「提示词 + 参数 + 成品图」 | 用户从画布一键「存为词条」 | 审核后进入公共池 |
| 私有词库 | 每个账号自己的收藏与常用词 | 自动 | 用户自己 |

### 5.3 交互要点

- **一键插入**：词条点击后插入到编辑器光标处，或作为「风格」追加到末尾。
- **参数联动**：选「推镜」时自动把运镜参数写到节点元数据，而不是只加一句文字。
- **AI 扩写/收敛**：基于当前节点已有词条，扩写成完整提示词，或把长提示词收敛成词条（反向沉淀）。
- **负面词独立区**：不同模型对负面词支持差异大，需要按模型能力显示。
- **多语言**：中文界面选词，实际提交英文（`en` 字段），避免中文模型兼容问题。

### 5.4 与已有能力的关系

现有 `/prompts` 是「远程来源聚合」，保留作为**社区来源**；新增 `PromptFacet` 作为**结构化词典**，两者在「灵感」页并列展示：左词典、右社区。

## 6. 材料库：从「我的资产」升级为「材料中心」

现状只有 `text/image/video` 三类、无标签、无授权信息，且存在浏览器本地（无法跨设备、无法团队共享）。

### 6.1 素材类型

| 类型 | 用途 | 现状 |
| --- | --- | --- |
| 图片 | 参考图、首帧、底图 | 有 |
| 视频 | 参考视频、片头片尾、转场 | 有 |
| 音频 | 配音、BGM、音效 | **缺** |
| 文字 | 脚本、文案、台词 | 有（弱） |
| 字体 / 图标 | 短剧字幕、电商主图 | **缺** |
| 品牌物料 | Logo、色板、产品图 | **缺**（电商刚需） |

### 6.2 关键能力

1. **标签与集合**：素材带 `tags`、`collectionId`、`source`（上传/生成/模板/购买）。
2. **授权标记**：`license: "own" | "ai-generated" | "licensed"`，避免客户拿商用素材踩坑。
3. **向量检索**（可选，后期）：以图搜图、以文搜图，短剧分镜素材量大时必需。
4. **与画布打通**：从材料库拖入画布 = 图片节点 / 参考图 / 首帧 / 角色卡，而不是复制粘贴。
5. **云端存储**：目前资产在浏览器本地，一旦做团队/客户交付必须上云（对象存储 + 元数据表）；这也是账户平台已有的基础设施延伸。

### 6.3 供给策略

- 内置一批**免费可用**的底素材：纯色背景、常用场景图、转场、BGM（注意授权）。
- 电商行业包：场景图 12 套（已有）、模特图、产品白底图。
- 短剧行业包：校园/都市/古风场景、服装、角色卡模板。

## 7. 差异化路线

**我们的独特组合 = 对话式方案生成 + 可编辑分镜画布 + 平台统一模型与积分。**

对比：

- 一站式创作台（即梦/可灵）：出片快，但改不动细节、拼不了长流程。
- 专业工作流（ComfyUI）：能拼长流程，但普通用户学不会。
- 我们：**用对话降低门槛，用画布保留可控性，用模板承载行业经验。**

这条路要求我们死守两个体验底线：

1. **一键可达**：任何模板，从「点一下」到「看到第一张成品」不超过 3 步。
2. **处处可改**：生成出来的每个节点都能单独重生成、改词、换模型，不锁死。

## 9. 需要先定的三件事

1. **素材要不要上云**：不上云，材料库永远只能是「个人本地收藏」，做不了团队与客户交付；上云就要考虑存储成本与版权合规。建议 v0.23 必须做。
2. **短剧是否要内置「剧本模型」**：用文本模型生成分镜 vs 用户自带剧本，两种产品形态差别很大。建议先做「用户给剧本 + AI 拆分镜」，不做「AI 写剧本」。
3. **模板由谁供给**：我们自营 vs 开放投稿。建议先自营 10 个高质量模板（电商 1 + 视频 6 + 短剧 3），跑通复用率再开放。

## 10. 衡量指标

- **激活**：新用户 24 小时内完成 1 次「模板 → 出图」的比例。
- **升级**：L1 用户在 7 天内做过 1 次视频生成的比例（这是从图到视频的关键跃迁）。
- **复用**：模板/词条被二次使用的次数（判断词库是否真的有用）。
- **留存**：7 日留存与「第二次创作」间隔。
