# 独立运营平台实施参数确认单

> 状态：已确认。以下参数已写回主 Spec，进入 M0 来源冻结和依赖闭包阶段。

## A. 推荐首期范围

| 项目 | 建议默认值 | 原因 |
| --- | --- | --- |
| 首期支付渠道 | 易支付 | 面向国内人民币充值，直接沿用 New API 已有配置与回调 |
| 后续支付渠道 | Stripe、Creem、Waffo 保留扩展位，首期不启用 | 缩小首期支付验收面 |
| 首期 Relay | 图片 + 文本 + 视频 + 音频 | 四类能力一次接入，共用报价、预占、结算和失败释放 |
| Redis | 生产必选，单实例 | 用于会话、限流、幂等锁和异步任务状态 |
| 邮件 | 标准 SMTP，由环境变量或管理员后台配置 | 支持注册验证和找回密码，不锁定邮件厂商 |
| 运行模式 | 同一代码库，部署时选择 `hosted` 或 `local`，单个实例只运行一种模式 | 避免运营钱包与本地自备 Key 状态混用 |
| 额度账户 | 统一可用额度，流水区分充值/赠送/邀请/补偿来源 | 用户只看到一个额度；邀请机制使用独立奖励流水和审计 |
| 赠送额度 | 首期不过期 | 避免首期引入批次到期和扣减顺序复杂度 |
| 兑换码/发票/工单 | 首期不做 | 先闭环注册、充值、生成和结算 |
| 邀请奖励 | 管理员配置邀请人奖励与被邀请人奖励 | 复用 New API 邀请码能力，奖励按配置版本快照入账 |

## B. 推荐基础设施

| 项目 | 建议默认值 |
| --- | --- |
| MySQL 数据库名 | `infinite_canvas` |
| MySQL 最低版本 | 8.0 |
| 字符集 | `utf8mb4` |
| 数据库存储时区 | UTC |
| 连接方式 | `DATABASE_DSN` 环境变量 |
| Redis 连接方式 | `REDIS_ADDR`, `REDIS_PASSWORD`, `REDIS_DB` 环境变量 |
| SMTP 连接方式 | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM` 环境变量；后台只显示脱敏状态 |

## C. 推荐行为边界

| 环节 | 建议默认值 | 失败处理 |
| --- | --- | --- |
| 用户会话 | 7 天；有操作滑动续期，最长 30 天 | 过期后要求重新登录，不清理本地画布 |
| 邮箱验证链接 | 30 分钟 | 过期后重新发送 |
| 密码重置链接 | 30 分钟，单次使用 | 使用后撤销该用户全部会话 |
| 登录失败限制 | 同账号或 IP 15 分钟内 5 次 | 冷却 15 分钟；不泄露账号是否存在 |
| 报价有效期 | 5 分钟 | 过期后重新报价，不创建任务 |
| 同步图片/文本上游超时 | 120 秒 | 明确失败则释放额度；未知状态转人工核查 |
| 渠道重试 | 仅请求尚未被上游接受时最多重试 1 次 | 有远端任务 ID 后禁止自动换渠道重复提交 |
| 用户并发 | 每用户同时 3 个生成任务 | 超限返回可重试错误，不预占额度 |
| 支付订单有效期 | 30 分钟 | 到期关闭；迟到回调进入人工核查 |
| 充值金额 | 最低 1 元，最高 5000 元/单 | 超范围拒绝创建订单 |
| 异步任务未知状态 | 保留 24 小时 | 期间只查询不重复提交；到期进入人工核查 |
| 上游实际成本高于预占 | 用户最多扣除预占额度，差额进入平台异常成本 | 不产生负余额；管理员可调整价格后续版本 |
| 任务取消 | 仅 `QUOTED`/`RESERVED` 且尚未发出上游请求时允许 | 全额释放；请求已发出后只标记取消意愿，按实际结果结算 |

浏览器项目和素材继续使用当前 localforage/IndexedDB，因此不在服务端定义“账户素材存储上限”。上传给模型的单文件大小上限应在各模型公开参数中由管理员配置，而不是全局写死。

## D. 确认结果与剩余决策

已确认：

1. 首期支付只启用易支付。
2. 首期同时接入图片、文本、视频、音频。
3. 采用统一额度，并加入管理员可配置的邀请奖励。
4. 采用同一代码库、按部署模式隔离 hosted/local。
5. 接受表 C 的会话、超时、重试、并发、订单和充值边界。
6. 兑换码、发票、退款申请页和客服工单放到首期之后。

邀请规则已确认：邀请关系注册时绑定，邮箱验证成功后发放奖励；邀请人和被邀请人奖励初始均为 0；每日上限、累计上限和风险审核规则由管理员后台配置；命中风险时进入人工审核，不自动发奖。
